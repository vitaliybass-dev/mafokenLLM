# mafokenLLM

mafokenLLM — отдельный рабочий чат на Mac: установленная модель Ollama по умолчанию, подключаемый API для сложных задач. Python 3.9+, JavaScript в браузере, без установки библиотек.

Дважды щёлкните «Запустить mafokenLLM.command» или выполните `/usr/bin/python3 server.py` из этой папки и откройте http://127.0.0.1:8769/. Окно Terminal с сервером можно оставить свёрнутым; при его закрытии приложение останавливается. Ollama должна отвечать на `127.0.0.1:11434`.

Для новой установки [установите и запустите Ollama](https://ollama.com/download/mac). Загрузите [Gemma 4](https://ollama.com/library/gemma4:12b) и создайте локальное имя модели для панели управления окном.

```sh
ollama pull gemma4:12b
ollama cp gemma4:12b gemma4:12b-backup
```

- **Для работы с проектом:** нажмите карандаш рядом со списком проектов, создайте проект и выберите папку кода. Отметьте только нужные файлы. Проект хранит выбранные снимки файлов и инструкции, исходники на диске могут измениться — для обновления замените снимки. Приложение не меняет исходники и не запускает сгенерированные команды. Скрытые каталоги, типовые файлы ключей и папки зависимостей исключаются из выбора.
- **Для правки кода:** выберите «Предложить diff» в поле формата ответа. Из ответа нажмите «В редактор», проверьте подсветку и скачайте `.patch`. Можно редактировать текст вручную и добавлять его к новому вопросу.
- **Для ежедневной переписки:** история поиска по чатам, закрепление, архив, скачивание в Markdown, редактирование в ветке, повтор последнего ответа, остановка потока, временные чаты. «Память и профиль» хранят явно указанные заметки и пожелания. Временный чат не сохраняет историю и не использует память.
- **Вложения:** текст и исходники, CSV/TSV, DOCX, XLSX, PDF с текстовым слоем (Poppler), PNG/JPEG/WebP для модели с распознаванием изображений. Материалы чата и изображения передаются в одном запросе; материалы проекта сохраняются отдельно и доступны в его чатах. Панель «Контекст запроса» показывает точные фрагменты. Если материал сокращён, перед отправкой приложение запросит подтверждение. Из таблиц извлекаются значения и простая статистика. OCR сканов отсутствует.
- **Голос:** запись до минуты, распознавание на Mac через `ffmpeg` и `whisper-cli`. По умолчанию используется `~/.cache/whisper/ggml-large-v3-turbo.bin`; можно задать абсолютный путь в `LOCALCHAT_WHISPER_MODEL`. «Озвучить» использует только установленный локальный голос браузера/macOS.

### Контроль расходов

В «Модели и сервисы» выберите OpenAI, DeepSeek, Claude, Gemini или свой HTTPS-адрес (Chat Completions или Anthropic Messages), укажите ключ и нажмите «Загрузить модели провайдера», чтобы получить каталог по этому ключу. Если у сервиса нет совместимого каталога, ID можно указать вручную. Запись в каталоге не гарантирует, что модель поддерживает выбранный формат чата. Ключи хранятся в памяти вкладки. История, проекты, черновики и настройки сохраняются локально. Каждый обычный чат восстанавливает свой неотправленный текст и вложения. Временный чат хранит их только в текущем сеансе.

- **Авто:** запрос может попасть во внешнюю модель только после разрешения в чате; сложность предварительно определяет локальная модель. Если в запросе есть файлы, а их отправка запрещена, он остаётся на Mac.
- **Только Mac:** всегда Ollama.
- **Только API:** выбранный провайдер отвечает при включённом разрешении. Для запроса с файлами нужно отдельно разрешить их отправку.
- На облачный ответ можно задать лимит выходных токенов. В меню чата можно ограничить число обращений к API в этом чате. Это лимиты запросов и ответа, не денег: провайдер также учитывает входные токены. Если есть данные об использовании, счётчик показывает полученные значения.
- Изначально внешняя модель получает только последнее сообщение. Разрешение на историю отправляет и предыдущие ответы модели, которые могут цитировать файлы. Разрешение на файлы и настройки передаёт сами материалы, инструкции и включённую память. Платный поиск, генерация изображений и фоновые агенты не встроены.

В режиме «Авто» при ошибке облачного API до начала ответа приложение продолжает запрос на Mac. Используется только уже выбранный провайдер и локальная модель. В настройках можно изменить локальную модель. Для гибридной маршрутизации без подключённого API дополнительных запросов для оценки сложности нет.

В боковой панели «Аккаунты и API» показаны сохранённые профили, модели и выбранный провайдер. «Проверить подключения» запрашивает баланс DeepSeek и проверяет доступ к метаданным модели для прямых подключений OpenAI, Claude и Gemini. Проверка отправляет только ключ и идентификатор модели, без запроса на генерацию. Для провайдеров без доступного остатка по API можно открыть кабинет или записать сумму вручную. Ручной остаток отображается с датой и автоматически не пересчитывается.

Кнопка «Выбрать модель» рядом с отправкой позволяет выбрать установленную модель Ollama, профиль API с конкретной моделью или тариф ChatGPT. Для тарифа можно загрузить модели, доступные аккаунту, и выбрать одну. Выбор действует для следующих сообщений и повторов в этом чате и сохраняется при повторном открытии обычного чата. Чтобы вернуться к исходному режиму, выберите «По умолчанию для режима чата». Если выбор блокируют настройки приватности или недоступность подключения, измените настройки или сам выбор; подмены модели нет.

Карточка рядом с «Отправить» показывает возможный источник следующего запроса: этот Mac, аккаунт/проект ключа API или подписка ChatGPT. Свою метку API аккаунта можно указать в настройках; провайдер не всегда сообщает владельца ключа. У ответа видны фактический источник, модель и счётчик токенов, если он передан. При возврате на Mac облачная попытка остаётся помеченной, а сумма уточняется у провайдера. В «Аккаунты и API» проверка без генерации и факт получения полного ответа показаны отдельно; входы только в браузере не подключают подписки к приложению.

В приложении macOS откройте «Аккаунты и API», нажмите «Войти через ChatGPT» и подтвердите использование тарифа на странице OpenAI. Затем выберите «Тариф ChatGPT» в чате и разрешите облако. Доступ зависит от тарифа и разрешений аккаунта. Режим отправляет текст, включая материалы проекта, только с соответствующими разрешениями в чате. Если модель не выбрана вручную, приложение берёт первую доступную модель из списка OpenAI. Учётные данные шифруются ключом из Связки ключей macOS. Claude, Gemini и DeepSeek открываются в официальных веб-чатах и используют сеанс браузера. При переносе mafokenLLM без скрытой папки `.siwc` установите компонент входа командой `./install-chatgpt.sh` (Node.js 22.12+, npm и инструменты командной строки Xcode).

## Приложение для macOS

Для сборки на macOS 14 и новее нужны инструменты командной строки Xcode. Если нужен вход через ChatGPT, сначала выполните `./install-chatgpt.sh` с установленным Node.js 22.12 или новее. Затем соберите и откройте приложение.

```sh
./macos/build.sh
open ~/Applications/mafokenLLM.app
```

Приложение открывается и из Finder. Оно запускает свой локальный сервер на порту 8771. История хранится в веб-хранилище приложения. Ранее сохранённые диалоги остаются доступны в браузере по исходному адресу.

В панели «Управление окном» разрешите mafokenLLM доступ в разделе «Универсальный доступ», выберите приложение и его окно и нажмите «Прочитать элементы». Предложите задачу Gemma или выберите элемент вручную. Перед нажатием или заменой текста проверьте окно, название элемента и содержание действия. Нажмите «Выполнить», чтобы разрешить один шаг.

Функция «Снимок окна» использует отдельное разрешение на запись экрана. Снимок можно сохранить или прикрепить к запросу, который выполнит локальная модель. Для входа через ChatGPT используется тот же локальный профиль. macOS может попросить разрешить приложению доступ к его записи в Связке ключей.
